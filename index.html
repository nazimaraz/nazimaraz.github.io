Featured · Embedded real-time · 2026

Real-Time Radar DSP

A hard real-time radar signal-processing pipeline on FreeRTOS, running bare metal on an emulated ARM Cortex-M4F (QEMU, MPS2-AN386) and written in C++23. Every 16 ms it takes a block of 256 ADC samples, applies a Hann window and a radix-2 FFT, and detects targets with CA-CFAR.

  • No heap. Dynamic allocation is off and the linker wraps malloc/free, so any heap use fails the build.
  • Own startup code, linker script and UART driver; no exceptions, no RTTI, no hidden runtime.
  • Zero-copy: tasks share four static buffers and pass only buffer indexes through queues.
  • Rate-monotonic priorities; missed deadlines, lost blocks and stack headroom are measured while it runs.
  • OS abstraction layer: porting to VxWorks or an ARINC 653 partition OS means a new backend, not a new pipeline.
  • C++23
  • FreeRTOS
  • ARM Cortex-M4F
  • QEMU
  • CMake
  • DSP

Try the detector

The same C++ that runs on the Cortex-M4F, compiled to WebAssembly. Move the tones, raise the noise or change the false-alarm probability and watch what CA-CFAR still detects. You can also drag a tone on the plot.

The sliders replace the simulated antenna. ADC encoding and decoding, the Hann window, FFT, power spectrum and CA-CFAR are the firmware's code.
